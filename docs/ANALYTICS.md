# Analytics

The first-party event model distinguishes product impressions from clicks and records placement. Trusted server events create purchases; client purchase events never determine revenue. Session and UTM context enable funnel and attribution reporting while avoiding unnecessary personal information.

Admin dashboards report catalogue engagement, conversion, revenue, inventory, promotion performance, cart recovery, reviews and operational queues. CSV exports and a Google Merchant XML feed are available. GA4, Meta Pixel and Meta Conversions API hooks are implemented but remain inactive until their environment variables are configured and production event deduplication is validated.
