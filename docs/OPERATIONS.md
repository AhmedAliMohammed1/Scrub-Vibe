# Operations

Implemented controls include role-scoped dashboards, payment webhook audit/deduplication, fulfilment queues, inventory alerts, return settlement, review moderation, recovery metrics and exports. Dashboards must not expose secrets or unnecessary customer data.

Before final sign-off, configure structured logs, correlation IDs, Sentry, distributed rate limiting, cron monitoring and provider credentials. Document and rehearse backup/restore, rollback and incident-response procedures. Paymob acceptance follows `PAYMOB_ACTIVATION.md`.
